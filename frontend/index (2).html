About CropAI

A Kubernetes-Based MLOps Framework for Scalable Deep Learning-Driven Crop Disease Detection in Smart Agriculture — Final Year B.E. Project

🎯 Problem Statement

Farmers lose 20–40% of crops annually due to plant diseases. Manual detection is slow, expensive and inaccurate. Small farmers cannot afford agricultural experts. Our AI system detects crop diseases instantly from a simple leaf photo, providing treatment recommendations to save crops.

💡 Our Solution

We built a complete end-to-end MLOps pipeline using EfficientNetB0 deep learning model trained on 54,306 PlantVillage images achieving 92.9% accuracy. The system is containerized with Docker, deployed on Kubernetes, served via FastAPI and monitored with Prometheus and Grafana.

🧠 Model Architecture

EfficientNetB0 CNN with Transfer Learning. Phase 1 trains top layers with frozen base. Phase 2 fine-tunes last layers with learning rate 0.0001. Two-phase training improved accuracy from 17% to 97.48% validation accuracy. Final test accuracy: 92.90%.

☸️ Deployment

Docker containerized application deployed on Kubernetes Minikube cluster with 2 pods running simultaneously. Auto-scaling and self-healing enabled. FastAPI serves predictions via REST API. Complete CI/CD pipeline with GitHub Actions for automated deployment.
